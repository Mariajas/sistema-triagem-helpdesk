# 🛠️ Sistema de Triagem - Help Desk TI & Ops

Este é um script automatizado em Python desenvolvido para otimizar o fluxo de atendimento em ambientes de suporte técnico e operações. O sistema realiza uma triagem inteligente de chamados abertos por usuários, analisando a descrição do problema e direcionando-o automaticamente para o setor correto com base em palavras-chave.

## 🚀 Funcionalidades do Projeto
* **Triagem Automatizada**: Identifica problemas de TI, Logística Reversa ou Faturamento de forma imediata.
* **Classificação de Prioridade**: Define níveis de urgência (Alta, Média ou Baixa) com base na criticidade das palavras-chave.
* **Direcionamento Assertivo**: Reduz o tempo de resposta ao encaminhar a demanda direto para a equipe responsável (Help Desk, Qualidade ou Portaria).

## 💻 Tecnologias Utilizadas
* **Lógica de Programação**: Estruturas condicionais avançadas (`if`, `elif`, `else`).
* **Manipulação de Strings**: Tratamento de dados com `.lower()` para evitar erros de digitação.
* **Linguagem Principal**: Python 3.x

## 🔧 Como Executar o Script
1. Certifique-se de possuir o Python instalado no seu computador.
2. Baixe o arquivo `main.py` deste repositório.
3. Abra o terminal na pasta do arquivo e execute o comando:
   ```bash
   python main.py
   ```
4. Siga as instruções na tela inserindo o seu nome e a descrição do chamado.
